## 事件

### AI-first 2D 游戏引擎方向讨论
- Sakana 想做 2D、code-first、AI 可直接写逻辑的游戏引擎/运行时
- 核心判断：最大难点不是图形，而是让 AI 能稳定操纵的引擎 API 设计
- 关键：API 抽象少而统一、生命周期明确、错误可修复、支持 headless test/replay/snapshot
- 候选技术栈对比：LÖVE（快速原型）、MonoGame（长期工程化）、raylib（自定义底盘）
- MonoGame 推荐为长期方案（XNA 精神续作，Stardew Valley/Celeste 背书）

### 地图系统与 AI 描述格式设计
- 现代 2D 地图是混合模式：tile 基础 + object layer + triggers/nav/spawn
- 建议三层表示：规划层（意图）→ 结构层（schema）→ 运行层（编译后）
- Prefab 概念对 AI 特别重要：写 `type: skeleton_archer` 而非手写全部组件
- 2D + 2.5D 视觉可做出 3D 观感（高度层 + 遮挡 + 阴影）

### UI 系统讨论
- HTML-like DSL 趋势但不建议嵌浏览器，借描述思想不搬技术栈
- MonoGame 推荐：Myra（游戏 UI）+ ImGui.NET（调试）
