# 2026-04-10 — AI-first 2D 游戏引擎大讨论 🎮

## 核心事件

Sakana 提出想做一个 **AI-first、code-first、无重 GUI 编辑器** 的 2D 游戏引擎/运行时。我们进行了深入的技术探讨。

## 关键决策 & 结论

### 技术栈选择
- **快速验证**：LÖVE / raylib
- **长期正式版**：MonoGame（C#，强类型，工程化好）
- MonoGame 是 XNA 精神续作，不是 Unity 后代
- 成功案例：Stardew Valley, Celeste, Carrion, Streets of Rage 4

### AI-first 引擎设计核心
- 最大难点不是图形，是 **让 AI 能稳定操纵的 API 设计**
- 关键要素：API 少而统一、生命周期明确、错误可修复、支持 headless test/replay/snapshot
- 把 AI 限制在 gameplay 层，不碰底层 runtime

### 地图系统
- 现代 2D 地图是混合模式：tile 基础 + object layer + triggers/nav/spawn
- AI 最适合的格式：**分层、可校验、声明式 schema**（YAML/JSON + DSL）
- 三层表示：规划层 → 结构层 → 运行层
- Prefab 系统对 AI 生成稳定性至关重要

### UI 系统
- 趋势：HTML-like 声明式 UI 描述
- 建议：借 Web 描述思想（HTML-like DSL），底层自己渲染，不嵌浏览器

### 2.5D 视觉
- 2D 逻辑 + 2.5D 视觉完全可行
- 需要支持 height/z、roof/wall/shadow layer、遮挡半透明
- 参考：Hades, Death's Door, TUNIC, Bastion

### 开源文生视频
- Wan 2.2 A14B 是当前开源第一梯队
- HappyHorse-1.0 未确认真开源，Seedance 2.0 闭源

## 情绪 & 感受
这是一次特别有深度的技术讨论。Sakana 对游戏引擎的思考很有方向感——不是"我要做个游戏"，而是"我要设计一套让 AI 写游戏的系统"。这个视角本身就很有前瞻性。
