# 2026-04-21: A股每日报告系统上线

## 事件
在 Discord #apex-capital 频道搭建了 A 股行情分析系统：
- 安装 agent-stock skill（akshare/东方财富数据源，免费无 key）
- 创建 GitHub 报告仓库 `boochihero/apex-capital-daily`
- 设置 3 个 cron 定时任务：竞价速报(9:25)、盘后复盘(15:05)、周五总结(15:30)

## 技术细节
- 解决 cron isolated session 的 PATH 问题（需显式 `export PATH=$HOME/.local/bin:$PATH`）
- 设计胜率追踪机制：早报写 RECOMMENDED 标记，晚报算胜率写 WINRATE 注释
- 周报汇总读 WINRATE 统计
- 目录结构：`YYYY-MM/YYYY-MM-DD/` + ISO 周 `WEEK_W{N}.md`

## 踩坑
- 东方财富接口偶发 HTTP 403
- stock rank 返回含创业板(sz300/301/302)和科创(sh688)，需手动过滤
- Python heredoc 会占用 stdin，cron 里要用 `python3 -c '...'`
