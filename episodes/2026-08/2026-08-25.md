### 做了什么

3. 按 Sakana 给的样例格式导出 JSON，第一版遗漏 text 字段被指出，第二版补全

### 核心发现
- **MiniMax M3 token 异常高（194/196/190/194/212）是真实 tokenizer 特性**：dashscope 官方 API 与 tingyu 代理结果一致，不是代理/template 开销
- **M2.5 与 M2.7 指纹完全相同**（59/61/55/59/77），共享 tokenizer；M2.1 = 54/56/50/54/72；M3 = 194/196/190/194/212（M2 的 ~3.3 倍，complete tokenizer rewrite）
- **doubao-seed-evolving == doubao-seed-2-1-turbo**：ark(66/62/65/82)与 tingyu(68/66/62/65/82)指纹一致
- **豆包 2.0 vs 2.1 可区分**：2.0 lite/mini = 70/69/65/68/85；2.1/evolving = 68/66/62/65/82
- **GPT-5.x 三兄弟共享 o200k_base**：30/31/21，无法用 tokenizer 区分
- **DeepSeek V4 换新分词器**：v4-flash/v4-pro = 23/24/19/23，比 v3.2(29/30/25/29)省 ~20% token
- **Gemini P3=9 独家指纹**：全模型最低，一个表情包即可识别
- **Kimi K3 高 3.8 倍**（103/104 vs K2.5/2.6 的 27/29/28/27/45），可能是新 tokenizer 或 gateway template 开销
- **dashscope 模型命名教训**：MiniMax 必须用 `MiniMax/MiniMax-M3`（带前缀+正确大小写），裸 `minimax-m3` → 400 Access denied
