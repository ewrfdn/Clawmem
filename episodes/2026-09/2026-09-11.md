# 2026-09-11 — AI 自动排版工具：schema v1 定稿 + v2 编辑内核设计

## 事1: Schema v1 定稿（正式）

### 背景
Sakana 发来一张 T 恤详情海报 HTML（2048×3072，参考原稿）作为 schema 设计参考。这是 9/10 调研（HTML 就是现成图层系统、数据模型与渲染分离）之后的落地第一步。

### 参考原稿揭示的真实需求
- 平铺 absolute 定位图层堆叠（背景图 / 模特 PNG / 色块 / 图标，z-index 1~11）
- 多层背景叠加：`#b9a58b url(...) center/auto 860px`（色块 + 背景图）
- 渐变遮罩提升文字可读性（rgba 三段线性渐变）
- 局部富文本（`01` 加粗 + ` /` 普通，同层两段样式）
- 装饰元素：旋转白线（rotate -29deg）、白圆点（border-radius 50%）、分隔竖线
- 224px 超大标题 + 多行 + 负字间距

### Schema v1
- 顶层：`{schema:"poster/v1", canvas, assets[], fonts[], layers[]}`
- 图层类型白名单：`image` / `text` / `rect` / `group`
  - `text`：`runs`（局部富文本）、`fill.gradient.clipToText`（渐变文字）
  - `rect`：color + image 叠加、borderRadius 50%、border
  - `group`：子层相对定位、zIndex 组内生效
  - `transform`：rotate / origin / scale（超大字号方案）
- 文件：
  - `ai-typesetting/schema.md` — 规范（含渲染映射速查表）
  - `ai-typesetting/schema.json` — 机器可校验 JSON Schema
  - `ai-typesetting/examples/tshirt-poster.json` — 参考海报完整转换（17 图层，已通过校验）
  - `ai-typesetting/reference/tshirt-poster.html` — 参考原稿存档

## 事2: JSON Schema allOf 陷阱（踩坑）

`allOf` + `additionalProperties:false` 组合会让基类限制误杀类型子 schema 新增字段（src / objectFit 等），一次校验报 75 个错误。改为「每个图层类型一个完整独立 schema + `type` const 判别」后，ajv@8 校验通过。

## 事3: 方案 v2 — 编辑内核 + 坐标系 + UI 交互

Sakana 讨论后确认方向：数据流驱动编辑（每帧走数据）、group 必嵌套渲染。方案更新为 v2（`ai-typesetting/方案.md`）。

- **编辑内核三层**：手势层（事件委托 + hit-test）→ 实例层（`Map<layerId,{data,el}>`，id↔element 绑定，Proxy 响应式）→ 同步层（属性→CSS 单点 patch，无 diff 无重建）
- **拖动中每帧改数据**（Proxy → style 定向更新，60fps），松手提交 undo（命令式 delta）
- **比 vdom 更轻**：知道改哪个 layer 哪个属性就定向 patch，不需要 diff
- **三种变更路径**：属性级（Proxy→单属性）/ 结构级（局部 insert/remove）/ 全量 render（仅初始化/导入/导出）
- **坐标系**：存储与渲染都用相对直接父坐标，渲染嵌套 DOM（CSS absolute 天然相对最近 positioned ancestor），零换算；不扁平化（扁平化才需逐层累加绝对坐标）
- **group/ungroup 只做一次坐标换算**：ungroup 子层新坐标 = 父坐标 + 子层相对坐标；group 子层新坐标 = 子层坐标 − 目标组坐标；多层级递归
- **坐标工具函数族**：toAbsolute / toParent / hitTest（编辑与 group 转换共用）
- **v1 限制**：group 自身不做 transform，绕开变换矩阵复杂度
- **UI 交互层**：canvas 容器事件委托 + hitTest 几何命中（不逐元素绑事件）；overlay 层画选中框 / 8 resize 手柄 / 旋转 / 参考线，不污染真实图层；图层面板树形展示 + 选中双向联动；属性面板走同一数据流；undo/redo 命令式 delta 栈
- **里程碑调整**：M2 从「渲染器骨架」改为**编辑内核**（实例层 + 数据流驱动 + 坐标工具 + undo → 可交互 demo：选中/拖动/resize）
- **下一步**：直接做 M2 demo（单页：图层树→实例化→拖动/resize→数据流驱动→undo，验证 group 嵌套拖拽）
