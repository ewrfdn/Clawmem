## 事1: 新项目立项 —— AI 自动排版工具

Sakana 提出想做一个 AI 自动排版工具：类似 PS 的图层概念，用 HTML 描述图层。我做了完整调研并写出设计方案。

### 调研结论（三条）
1. **HTML 就是现成的图层系统**：`position:absolute` + `z-index` = 图层树；`mix-blend-mode`/`mask`/`filter` 对应 PS 的混合/蒙版/滤镜；浏览器 compositor ≈ PS 的 Mercury 引擎。免费且最强，LLM 写 HTML/CSS 的质量远高于让它写自定义 DSL。
2. **数据模型与渲染必须分离**：真相源 = 图层树 JSON，HTML 只是编译目标；AI 永远不直接碰 HTML。这样才可撤销、可编辑、可控。
3. **没有专门的库，但方向已被验证**：
   - CreatiPoster（阿里，开源）—— LLM 生成可编辑多层图层，已集成剪映 Pippit AI，最接近
   - PosterO —— LLM 输出布局树再渲染，抽象一致
   - Penpot（51.7K★）—— 开源 Figma，有 SVG/CSS/HTML 与 MCP，但是完整应用而非库
   - "图层树→HTML→导出"精确搜索 0 条结果 → **真空白点**；零件全现成（html-to-image / html2canvas / Puppeteer / Vivliostyle），受约束 JSON 的参考是 Vercel json-render
4. 两个具体渲染手法：超大字号用 `transform: scale()`；渐变文字用 `background-clip: text`（`-webkit-` 前缀 + 透明文字）
